This is a project I did three months into coding. I hoped it would help students learn coding easily, so I included a coding sandbox. I had a great vision; I wanted to integrate YouTube so that the user can watch a tutorial on YouTube and simultaneously practice, but I was unable to do it because at the time I was yet to learn how to absorb external APIs. I also wanted to integrate Chat GPT so that users can find answers to question that may not be answered by the content. Despite the shortcomings in this project and the eventual submission of this version I have not yet lost hope in it and now that I am better equipped to bring out my vision I decided to give this another chance. Right now the dream is definitely larger but I intend to bring out my vision this time so that the next generation of developers can have what I never had during my initial learning phase, and I hope when I am done it is a software that can be leveraged in various training environments both in tech and otherwise.

the best part of this whole project was the coding sandbox. I always feel really ecstatic when I run a line of code and see the output I expected, so seeing the expected output in the sandbox console was a surreal feeling for me.
